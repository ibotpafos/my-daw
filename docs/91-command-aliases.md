# Свои названия команд — пользовательские aliases

## Источник и границы

Закрывает следующий пункт [документации палитры](79-command-palette.md):
пользовательские aliases. Разработано поверх main `660c0e4`, уже включающего
workspace, Mixer, Piano Roll, навигатор аранжировки и Command Palette.
Это синонимы **поиска**, не новые горячие клавиши, макросы, shell-команды или ИИ.

## Как пользоваться

Открыть палитру по `⌘K`, найти и выделить команду, нажать **«Свои названия…»**.
Редактор открывается внутри окна, без модального диалога. Например, для экспорта
можно ввести `рендер; bounce; mix down`. **Сохранить** или Return подтверждает
изменение; пустое поле удаляет только названия этой команды. Escape отменяет
редактирование и возвращает фокус поиску; следующий Escape закрывает палитру.
`⌘K` закрывает всю палитру и отбрасывает несохранённый текст, но не прерывает
marked-text composition. Закрытие окна/потеря фокуса также не сохраняют черновик.

Оригинальное название команды и shortcut остаются видимыми. Синонимы показаны
во второй строке и доступны в tooltip/accessibility label. Они работают во всех
трёх режимах выдачи, но не обходят фильтры «Недавние / Частые». Точное оригинальное
имя ранжируется выше такого же синонима; точный синоним выше неполного совпадения.
Используется прежний Unicode case/diacritic folding и fuzzy-поиск. Несколько слов
могут совпасть с одним синонимом и путём меню; слова из разных синонимов не
склеиваются в выдуманное название. Команда показывается ровно одной строкой.

Одинаковый синоним у разных команд допускается: обе видны под оригинальными
названиями, никакая команда не перезаписывается. Это поисковая выдача, а не
автоматическое выполнение по введённому слову. Пользователь по-прежнему выбирает
результат и подтверждает штатное действие.

## Безопасность UI и данных

Редактор захватывает стабильный ID именно открытой для изменения команды.
Выбор другой строки не переназначает черновик. Пока редактор открыт, Return и
двойной клик по таблице не выполняют команды DAW. Ошибка валидации оставляет
редактор и прежние настройки; скрытая или удалённая команда не возрождается из
сохранённых синонимов. При выполнении продолжают действовать прежние проверки
menu item/target/action/tag. История учитывает ID исходной команды, не её синоним.

Названия сохраняются в `UserDefaults`, отдельный ключ `commandPalette.aliases.v1`,
JSON envelope version 1. Не более 256 команд, до 8 названий на каждую, максимум
48 символов и 192 UTF-8 байта на название, ID до 2048 UTF-8 байт, JSON до 256 KiB
**после экранирования**. Нулевые/управляющие символы и `;` внутри отдельного
названия запрещены. Пробелы нормализуются, эквивалентные названия одной команды
не дублируются. Превышение лимитов отклоняет запись целиком, без вытеснения других
команд. Пустой список удаляет запись; удаление последней очищает только этот ключ.

Открытие настроек ничего не записывает. Перед изменением перечитывается актуальное
значение, чтобы две палитры не затирали разные настройки друг друга. Это защита
между окнами одного процесса на MainActor, не транзакционная синхронизация разных
запущенных экземпляров приложения. Повреждённый JSON/неизвестная версия/oversize
дают пустую модель; неверные записи отбрасываются при загрузке.

Используются те же ID, что у истории: явный `NSMenuItem.identifier` устойчив к
локализации. Fallback-ID зависит от названия/пути/selector/tag; переименование
пункта без identifier не переносит старые синонимы. Текст запросов не сохраняется.
Очистка истории не удаляет названия. Поиск и редактирование названий не обращаются
к C ABI, не изменяют project format, revision, Undo или audio graph.

## Переиспользование и проверки

Foundation Codable/JSONEncoder/UserDefaults, AppKit NSTextField/NSButton,
NSControlTextEditingDelegate и прежний поиск/dispatch. Никаких новых зависимостей
или собственного DSP. Собственный код — ограниченная модель preferences и UI.
Первоисточники: [UserDefaults](https://developer.apple.com/documentation/foundation/userdefaults),
[NSTextField](https://developer.apple.com/documentation/appkit/nstextfield) и
[делегат редактирования](https://developer.apple.com/documentation/appkit/nscontroltexteditingdelegate).

`bash scripts/test-command-palette.sh` сохраняет старые 50 model checks, добавляет
466 alias checks (в том числе 400 последовательных edit/remove/restart проверок)
и расширяет настоящий AppKit harness: кнопки, native field editor, Return/Escape,
ошибки, смена selection, persistence, поиск и dispatch исходной команды, отказ
устаревшего действия. Снимки `command-alias-editor.png` и
`command-alias-search.png` создаются настоящим AppKit в CI, не генератором изображений.
Точные результаты macOS-прогона записываются в PR; наличие теста не равно его запуску.
Физическая клавиатура/IME, полный VoiceOver audit и интерактивная ручная приёмка
остаются отдельными gates, как и у базовой палитры.
