# Split и несколько клипов — 0.6.0

14 сентября 2026. Дорожка теперь содержит один неизменяемый аудиоисточник и до 256 недеструктивных монтажных клипов. Кнопка Split разрезает выбранный клип в позиции курсора. Операция атомарна, поддерживает Undo/Redo и не копирует PCM.

## Управление

- Клик по клипу выбирает его и одновременно ставит курсор.
- Кнопка Split делит выбранный клип строго внутри его границ. Разрез на краю отклоняется без изменения проекта.
- После разреза выбирается правая половина. «Клип…», drag за края и ⌥ + drag работают с выбранным клипом.
- Две половины сохраняют непрерывное соответствие исходнику: длина левой части прибавляется к source offset правой. Суммарная длительность материала не меняется.

В одной дорожке клипы не могут перекрываться. После перемещения порядок нормализуется по позиции; конфликтующая геометрия отклоняется целиком. Между клипами может быть тишина. Delete, копирование, склейка, snap/grid, fades и crossfades пока отсутствуют.

## Модель и звук

`Track` хранит `vector<Region>`, где Region содержит timeline start, source offset и length в кадрах 48 kHz. Один shared immutable Clip остаётся источником всех регионов дорожки. Лимиты: 256 регионов на аудиодорожку, 8 аудиодорожек, 64 MiB декодированного PCM, 10 минут таймлайна.

Renderer создаёт voice для каждого региона, но gain и его сглаживание принадлежат дорожке. Поэтому соседние половины Split не перезапускают gain ramp на границе и сохраняют исходное timeline/source mapping. Fades ещё нет, поэтому раздельно перемещённые или обрезанные клипы могут щёлкать на ненулевом sample.

## Формат

Экспериментальный черновик получил `user_version = 4`. Таблица tracks хранит дорожку и PCM, новая таблица regions — упорядоченную геометрию клипов. Reader принимает v1–v3 и преобразует прежний единственный клип в один Region. Старые сборки формат v4 не открывают.

## Проверка

4/4 CTest прошли в Debug и 4/4 с ASan/UBSan. Проверены: точный разрез 100-кадрового региона на две части, непрерывный source offset, отказ на обоих краях, Undo/Redo, C ABI get/split, сохранение v4 и повторный рендер. Crash-тесты фонового writer продолжают проходить после изменения схемы.

В нативном приложении исходный пользовательский файл v3 открыт без изменения. Для проверки создана отдельная `build/Audio demo - split test.mydawdraft`: клип с start 53 364 разрезан на timeline frame 96 000. Получены регионы `(53 364, 0, 42 636)` и `(96 000, 42 636, 533 364)`. UI показал 1 → 2 клипа, Undo вернул 1, Redo — 2; сохранённый файл имеет revision 19, user_version 4 и `quick_check = ok`.

Это функциональное доказательство модели и UI, но не listening acceptance. Физическое прослушивание границы Split, длительная нагрузка сотнями регионов и профилирование callback ещё не выполнены.
