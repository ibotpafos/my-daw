# Piano Roll: транзакции редактирования и интеграция с проектом

## Источник данных и запись

Сохранёнными данными остаются ноты C ABI в clip-relative кадрах 48 кГц.
`PRBridge` выполняется только на MainActor, то есть на owning thread сессии.
Ни отдельного формата проекта, ни локального Undo, ни нового DSP здесь нет.

Снимок содержит UUID открытого документа, ID дорожки, индекс клипа, ревизию,
полные границы и весь массив нот. UUID меняется при New, Open и восстановлении
черновика, даже когда загруженный файл имеет такую же сохранённую ревизию.
Загрузка метаданных/страниц сверяет ревизию до и после чтения; неверная или
неполная страница отключает редактор, а не публикуется как редактируемый префикс.

Перед `daw_set_midi_notes` адаптер проверяет текущий документ, захват аудио/MIDI,
ревизию, границы и исходные ноты. Вызов получает **сохранённую ревизию операции**,
а не новое значение из инспектора. Применение и отказ возвращают полный снимок.
Смена выделенной дорожки не перенаправляет старую операцию в другой клип.

Полная замена поддерживает до 65536 нот (`DAW_MIDI_NOTES_PER_REPLACEMENT`), потому
что покадровый редактор должен записывать клипы больше одной страницы атомарно.
Лимит страницы и батча add/append остаётся 8192; общий бюджет всех MIDI-клипов
по-прежнему проверяет domain. Это совместимое расширение ограничения вызова,
без изменения POD, версии базы данных или механизма project Undo.

## Жесты и подтверждение

Каждый жест имеет UUID. Canvas и velocity lane сохраняют свой UUID: поздний
mouse-up, preview или cancel не может закончить новый жест другого элемента.
Неверный последний pointer-кандидат очищает предыдущий preview. Ratchet,
Strum и Velocity Ramp пересчитываются от исходного снимка, а не от предыдущего
предпросмотра. Apply повторно читает активную панель, включая ещё не отправленный
текст поля velocity; ошибочный ввод не применяет старый корректный кандидат.

До подтверждения сохраняется последний авторитетный массив. Отсутствие callback
отказывает до отправки; callback без echo блокирует дальнейшую запись до refresh.
Отклонённые удаление, вставка и ratchet восстанавливают исходное выделение, а не
идентичность несуществующих новых нот. Reentrant смена документа в `onChange`
отменяет ещё не отправленный callback. Все команды, включая chord stamp,
подчиняются общей блокировке active gesture / capture / pending commit.

Инспектор заменяет context/metadata/notes одним вызовом `apply(model:)`.
Повторный снимок той же ревизии не прерывает drag. Лёгкая проверка ревизии и
захвата идёт через существующий timer; полное чтение выполняется при изменениях.

## Поверхности

Toolbar разделён на два ряда. Длинный числовой/transform/chord инспектор
прокручивается внутри окна. Сила квантования доступна в диапазоне 0–100%.
Шорткат Cmd-Z распознаёт физическую клавишу также в русской раскладке.
Ghost loader ограничивает именно число **прочитанных** нот (4096), а не только
число показанных; дополнительно ограничены обращения к метаданным (256 клипов).
Ghost notes остаются визуальными, без hit-testing и без записи в проект.

## Воспроизводимые проверки

```sh
bash scripts/test-piano-roll-transforms.sh
cmake --preset debug
cmake --build --preset debug -j 3
bash scripts/test-piano-roll-bridge.sh
ctest --preset debug --output-on-failure
python3 scripts/check_docs.py --require-schemas
python3 scripts/e2e_coverage.py --strict
```

На macOS дополнительно:

```sh
bash scripts/typecheck-macos-ui.sh
PR_QA_DIR="$PWD/build/qa-ui" bash scripts/test-piano-roll-appkit.sh
bash scripts/build-macos.sh
bash scripts/test-piano-roll-bridge.sh
```

`TransactionSafetyTests` проверяет отсутствие echo, отказ host, disabled/preview
для всех путей мутации, смену контекста, reentrancy, поздние UUID и ID overflow.
`BridgeIntegrationTests` использует настоящую C ABI сессию: чтение 8195 нот в две
страницы, групповая MIDI-правка из `PRProState`, ровно одна ревизия, project
Undo/Redo, save/open, stale/invalid/partial-source отказ и undo очистки клипа.
E2E MIDI/tempo отдельно заменяет 9000 нот одной командой и отменяет её.

AppKit smoke создаёт реальные NSView/NSWindow, передаёт события клавиш/мыши,
проверяет размеры и прокрутку инспектора. PNG-артефакты 1280 и 980 px снимаются
с настоящего AppKit workspace, не являются дизайнерскими мокапами.

Наличие теста не означает успешный прогон: результаты указываются для конкретного
commit/run в PR. Linux не проверяет macOS SDK или GUI. Полная совместимость
AU/VST3, слышимое audition клавиатуры, ручное drag/scroll/VoiceOver и физический
MIDI-контроллер остаются отдельными гейтами. CC, expression, pitch bend,
aftertouch/MPE не имитируются UI-only элементами.
