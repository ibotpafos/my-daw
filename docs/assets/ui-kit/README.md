# UI kit visual catalog

Open `catalog.html` locally. It is self-contained and documents the approved visual direction, semantic color roles, interaction states, spacing, type scale, and every semantic SF Symbol mapping from `apps/macos/DesignSystem/DAWIcon.swift`.

The companion SVGs are scalable fallback/reference sheets. Runtime macOS UI should prefer the native Symbol mapping to retain optical alignment, Dynamic Type behavior, accessibility labels, and platform rendering.

`approved-reference.png` preserves the user-approved generated direction used for this kit. It is a design reference, not a runtime asset and is not copied into the application bundle.
