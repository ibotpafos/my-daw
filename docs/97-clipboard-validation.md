## Выполненные проверки до нативного CI

На исходниках нового clipboard-среза перед форматированием:

- Linux Debug: 41/41 CTest, без ошибок и пропусков.
- Linux AddressSanitizer / UndefinedBehaviorSanitizer: 41/41 CTest,
  без ошибок и пропусков. Включены новые `clip_clipboard_model` и
  `e2e_clip_clipboard`, прежние проверки ядра сохранены.
- Документация/схемы/SQL: обязательный `check_docs.py --require-schemas` прошёл.
- Layout/manifest: 6/6 тестов. Strict E2E ledger: 235 public ABI,
  233 E2E, 2 существующих ручных hardware gates, 0 uncovered.
- Синтаксический разбор Swift прошёл. Это не нативная проверка типов и не запуск UI.

E2E проверяет копирование/вырезание групп, повторную вставку после изменения и
удаления оригинала, Undo/Redo, ошибки capacity/overlap/stale/null, Save/Open,
пустую аудиодорожку и реальную амплитуду/тишину в экспортированном WAV через
независимый reader. Наличие unit-теста не подменяет публичный пользовательский путь.
