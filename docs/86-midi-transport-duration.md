# 86. Длительность MIDI-проекта в остановленном транспорте

## Причина изменения

Интеграционный тест [настоящего VST3-инструмента](85-vst3-instrument-source.md)
прошёл рендер ноты на кадре 137 для блоков 64/257/4096, Undo/Redo и сохранение
проекта, но остановился на чтении транспорта после `daw_open_draft`:
`Bridge did not expose MIDI duration`.

В `engine/bridge/daw.cpp` локальный `duration()` учитывал только аудиорегионы.
`Renderer` уже включал `midiClips`, поэтому один MIDI-only проект имел разную
длину до и после подготовки аудиоустройства. Это не ошибка самого синтезатора.
По тому же helper ограничивались `daw_seek_frame` и `daw_set_loop`.

## Исправление

Существующий helper теперь берёт максимум `start + length` как аудиорегионов,
так и MIDI-клипов всех дорожек. Для MIDI используются те же проверенные
доменом границы, что и у renderer; дополнительного движка длительности,
формата хранения, экспортируемого ABI и зависимости нет. Пустой проект
по-прежнему имеет длину ноль. Чтение длительности и навигация не создают Undo.

## Независимая регрессия без SDK и железа

В прежний CTest `midi_bridge` добавлены проверки:

- ноль кадров в пустой сессии и 48000 кадров после добавления MIDI-клипа;
- seek на кадр 137 и loop до конца клипа допустимы; выход за пределы отвергается;
- move расширяет длительность до 58000, split сохраняет конец, trim сокращает
  до 10600; Undo/Redo восстанавливают соответствующие значения;
- после удаления последнего клипа длина снова ноль и ненулевой seek/loop
  недопустимы; навигация не меняет revision.

Проверки выполняются в обычном Linux/macOS CI без плагинов и физических
устройств. Новый SDK-тест остаётся независимым сквозным сценарием:
реальный инструмент → сохранение/открытие → транспорт → публичный WAV-экспорт.
Ни одна из проверок первого красного прогона не удалена.

```sh
cmake --preset sanitizers
cmake --build --preset sanitizers --target daw_midi_bridge_tests --parallel 2
ctest --preset sanitizers -R '^midi_bridge$' --output-on-failure --no-tests=error
```

Результат конкретного запуска, head/merge SHA и артефакты публикуются в PR #7;
описание проверки само по себе не заменяет исполненный тест.

## Следующий UI-пункт

Основной `exportMix`/`exportButton` пока имеет старый `hasAudio`-gate.
Доступность основного диалога для MIDI-only проекта отслеживается отдельно
в [issue #9](https://github.com/ibotpafos/my-daw/issues/9). Исправление длительности
C ABI не объявляется исправлением этого диалога. Физическое воспроизведение,
живой мониторинг и совместимость со всеми VST3 также не следуют из этих тестов.
