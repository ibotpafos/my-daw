# Параметры в нижней панели устройств

Reference workspace: кнопка «В панели» открывает сохранённые параметры выбранной
AU/VST3-вставки непосредственно в её карточке. Одновременно развёрнута одна
карточка; четыре параметра на странице. «Все…» оставляет доступ к прежнему
редактору параметров и автоматизации. Плагины не сканируются при открытии пустой
панели и при обновлении транспорта.

## Реальные значения и границы

Используются существующие `daw_get_insert_parameter_count`,
`daw_get_insert_parameter` и `daw_set_insert_parameter`. Это состояние,
сохранённое в проекте, а не измерение текущей автоматизации и не vendor GUI.
После изменения/Undo/Redo видимая страница перечитывается из хоста. Числа не
обновляются оптимистически. Чтение параметров выполняется синхронно на владельце
сессии, как в прежнем редакторе; медленный сторонний плагин может задержать UI.
VST3 путь уже кеширует свою метаинформацию; AU путь пока создаёт временные
экземпляры для существующих запросов. Новое UI не скрывает это ограничение.

Нативный `NSSlider` circular + поле числа: действие ручки отправляется после
отпускания, поле — по Enter. Одна команда меняет сохранённое состояние и создаёт
одну Undo-запись. Как и прежний редактор, подтверждение останавливает playback;
это не live DSP automation. Неизменённое native Float значение — no-op.
Поддерживается десятичная запятая; NaN/Inf/переполнение/выход за диапазон
отклоняются. Положительные logarithmic диапазоны отображаются логарифмически.
Только writable-параметры с ненулевым диапазоном можно менять.

VST3 через текущий ABI предоставляет нормализованные значения 0…1 без native
units/числа ступеней; интерфейс это подписывает и не изобретает Hz/dB/проценты.
`indexed` сам по себе не даёт оснований округлять значение до 0 или 1.

Во время аудиозаписи, MIDI capture и активного жеста автоматизации изменения
запрещены. UUID запроса, владелец, plugin ID и фактическая revision проверяются
перед командой. Refresh, смена страницы/канала или переоткрытие проекта делают
старые callbacks недействительными, даже когда числовые ID совпали. Ошибки
новой команды выводятся без блокирующего NSAlert. Delete с фокусом на ручке
не передаётся глобальной команде удаления клипов аранжировки.

## Переиспользование / проверка

Новые DSP, framework и project storage model не добавлены. AppKit предоставляет
tracking, focus, числовой ввод и target/action. Собственный код — форматирование,
геометрия карточки, проверка контекста и адаптер к существующему C ABI.

Первоисточники: [NSSlider.sliderType](https://developer.apple.com/documentation/appkit/nsslider/slidertype-swift.property),
[NSControl.isContinuous](https://developer.apple.com/documentation/appkit/nscontrol/iscontinuous).

`tests/rack_parameter_tests.swift` проверяет чистые диапазоны и преобразования.
`tests/workspace_parameter_tests.swift` использует настоящий системный AU через
производственный контроллер: кнопки/ручка/числовой ввод, постраничный просмотр,
no-op/invalid/stale guards, Undo/Redo, save/open и отсутствие запросов при poll.
Оба включены в `bash scripts/test-workspace-ui.sh`. Снимки UI выполняются без SDK;
отдельный VST3 workflow компилирует то же UI с реальным VST3-хостом. Физические
устройства, сторонние плагины и взаимодействие в активном окне — manual gates.
