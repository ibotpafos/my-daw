# Command Palette

## Зачем

Продуктовая документация требует keyboard-first палитру команд: пользователь должен быстро вызвать существующее действие по намерению, не запоминая меню и shortcut. Палитра не должна становиться вторым реестром команд — иначе меню, shortcuts и palette начнут расходиться.

## Первый вертикальный срез

- `⌘K` открывает и закрывает палитру из главного окна, в том числе когда фокус находится в текстовом поле.
- Источник команд — актуальное `NSApp.mainMenu`. В индекс попадают только видимые, enabled leaf-команды с валидным AppKit target/action.
- Перед показом палитры nil-target действия разрешаются через responder chain. При запуске выбранной команды палитра закрывается, главное окно снова становится key, затем вызывается сохранённый target/action.
- Поиск учитывает название, путь меню и shortcut. Exact/prefix/word-prefix получают больший вес; затем substring и компактный subsequence fallback.
- Пустой запрос сохраняет естественный порядок меню; одинаково релевантные результаты также не прыгают между запросами.
- Полностью keyboard-first навигация: `↑/↓`, `Return`, `Esc`; мышью доступен double-click.
- Overlay остаётся отдельным AppKit surface и не меняет project/domain state, поэтому открытие и поиск не создают Undo/revision.

## Accessibility

Поле поиска и список результатов имеют accessibility labels/help. Название команды, путь меню и shortcut представлены обычными AppKit text controls; палитра не зависит от custom-drawn canvas.

## Проверки

`tests/macos_command_palette_search_tests.swift` проверяет prefix, multi-token, fuzzy abbreviation, поиск по shortcut, отсутствие ложных результатов и стабильный порядок. `scripts/test-command-palette.sh` компилирует этот слой отдельно; macOS CI запускает его до сборки приложения.

## Дальше

Следующий срез может добавить последние/частые команды, sectioning, явные project-context команды без пункта меню и пользовательские aliases. Для таких команд сначала нужен общий command registry; до его появления меню остаётся единственным источником истины, чтобы не дублировать семантику действий.
