# Offline WAV export — 1.0.0

15 сентября 2026. My DAW экспортирует весь слышимый диапазон проекта в stereo WAV 48 кГц: PCM24 с TPDF-дизерингом или IEEE float32. Команда доступна в панели и меню «Файл». Рендер выполняется в фоне, показывает прогресс и не блокирует дальнейший монтаж.

## Один рендер для Play и Export

Экспорт подготавливает обычный `Renderer` из неизменяемого снимка `State` и вызывает его блоками по 4096 кадров от нулевой позиции до конца последнего региона. Поэтому в результат входят те же перекрытия регионов, fades, gain smoothing и суммирование дорожек, что в Play. Изменения проекта после запуска относятся к следующему экспорту; сообщение о завершении показывает ревизию использованного снимка.

Текущий Play применяет safety clamp `[-1, 1]` и считает перегруженные кадры внутри renderer. Float32 WAV сохраняет именно этот результат без нормализации и целочисленного квантования. Это обеспечивает проверяемое совпадение прототипа, но пока не даёт unclipped float master выше 0 dBFS. Такой режим появится после переноса защиты в Core Audio output adapter.

## Форматы

| Выбор | WAV encoding | Поведение |
|---|---|---|
| WAV 24-bit | stereo PCM, 24 bit, 48 кГц | Один детерминированный TPDF dither перед финальным квантованием |
| WAV float32 | stereo IEEE float, 32 bit, 48 кГц | Float samples renderer без PCM-квантования; записывается `fact` chunk |

TPDF использует фиксированное начальное состояние небольшого PRNG. Повторный экспорт одного снимка даёт тот же PCM24-файл, что упрощает регрессионные тесты. Dither применяется только один раз в final writer.

## Фон, отмена и файл

C bridge захватывает копию состояния на owning thread, после чего detached worker больше не обращается к `daw_session`. UI опрашивает счётчики готовых и общих кадров. Одновременно приложение держит не больше одной ручной задачи экспорта; запись нового входа начинается после её завершения или отмены.

Writer создаёт временный файл в `NSItemReplacementDirectory` на томе назначения, записывает header и аудио, вызывает `fsync`, закрывает descriptor и только затем делает rename в выбранное имя. При отмене или ошибке временный файл удаляется, а существующий целевой WAV остаётся прежним. Финальное имя не содержит частичного результата.

## Проверка и пределы

CTest `offline_wav_export` проверяет точное совпадение декодированного float32 с playback renderer, заголовки обоих форматов, PCM24 с допуском квантования, неизменность существующего файла при отмене, отказ пустого проекта и полный асинхронный путь C bridge. В Debug и ASan/UBSan весь набор проходит 6/6.

Версия 1.1 добавила выбор range и использует тот же путь для его экспорта. Версия 1.33 добавляет [явную политику infinite tail](60-infinite-tail-export-policy.md): automatic bounded tail, исключение infinite component и лимиты 2/5/15/30 секунд при сохранении finite decay. Пока нет sample-rate conversion, метаданных или realtime bounce для плагинов; с 1.56.0 есть файловый LUFS/true-peak метр готового экспорта (см. ниже). Автоматические тесты не заменяют прослушивание на физическом выходе; ручная приёмка PCM24 и float32 остаётся открытой.

## Стемы по дорожкам (1.53.0)

`writeStems(snapshot, directory, format, options, progress)` и job-обёртка `startStemExport` пишут по одному WAV на слышимую дорожку. Снимок стема синтезируется: solo только на этой дорожке (мьют/соло/automation/инсерты дорожки едут с ней), мастер-гейн в единицу, мастер-цепочка и мастер-automation обходятся — по конвенции стемы лежат **до** мастера, и их сумма с исходным мастер-гейном даёт микс. Pre-fader посылы не текут из замьюченных дорожек (гейт `preFaderGates` в рендерере), так что стем не слышит чужого bleed. Имена файлов — `NN - <дорожка>.wav` с санитизацией (буквы/цифры/пробел/`-_.` сохраняются, остальное `_`; индекс уникален). Пользовательская замьюченная дорожка, дорожка без материала и дорожка с одними замьюченными клипами честно пропускается; если слышимых нет — «No audible track to export». Отмена действует между файлами, прогресс — кадры, накопленные по всем стемам. Range-выбор на стемы не распространяется: всегда весь проект.

Мост: `daw_begin_stem_export(session, directory, format, options)` — тот же job-цикл poll/cancel/release, что и у микса. UI: «Файл → Экспортировать стемы…» — тот же диалог tail-политики, затем NSOpenPanel выбора папки.

CTest `offline_wav_export` добирает: содержимое стема совпадает с фейдерной рампой (0.5 и −0.25 по глобальному сглаживанию), «01 - Lead_Vox.wav» из «Lead/Vox» (санитизация), третий файл отсутствует, хвост суммы стемов сходится с миксом при мастер −2 dB, reject несуществующей папки и reject полностью тихого проекта.

## LUFS и true-peak (1.56.0)

Новый модуль `engine/audio/loudness.{hpp,cpp}`: integrated loudness по ITU-R BS.1770-4 — K-weighting (полочный +4 dB и RLB high-pass биквады, коэффициенты 48 кГц из Annex 1), 400-мс гейт-блоки с 75% перекрытием, абсолютный (−70 LUFS) и относительный (−10 LU) гейты, веса каналов L=R=1.0; файлы короче блока измеряются целиком. True-peak — 4× oversampling полифазным КИХ (48-отводное windowed sinc, срез на исходном Найквисте). Опорные точки в CTest: фулл-скей 997/1000 Гц синус ≈ 0 LUFS (−3.01 RMS + ≈0.7 дБ K-взвешивания на килогерце), масштабирование амплитуды 1:1 по LUFS, синусовый пик в найквист-точном TP без превышения 0 dBFS, Гиббсов перелёт меандра ловится как +0.2…2.5 dBTP, тишина — гейт-молчание с sentinel −400.
Мост `daw_measure_wav(session, path, daw_loudness_report*)` читает готовый WAV и отдаёт отчёт (ABI-гейт по struct_size, нечитаемые файлы — отказ; гейты покрыты `pure_c_bridge`). UI: по завершении экспорта единичного WAV сообщение дополняется «· −13.9 LUFS · −0.4 dBTP» (или «тише -70 LUFS»); папки стемов помечаются «стемы в папке». Это файловый метр готового бунса; с 1.57.0 есть и realtime-метр мастера (см. ниже).

## Realtime-метр мастера (1.57.0)

`MasterLoudnessTracker` (тот же `engine/audio/loudness`) считает моментальную (400 мс) и краткосрочную (3 с) громкость по BS.1770-4 прямо в RT-пути: K-weighting-биквады (общие коэффициенты с офлайн-путём), энергетические блоки по 100 мс на фиксированном кольце из 30 слотов, скользящие окна 4/30 блоков — без аллокаций в колбэке, публикация атомарным store на границе блока. Меряется программный выход после мастер-эффектов и ДО метронома (щелчок — мониторинг, не материал). Мост `daw_get_master_loudness` (ABI-гейт; `live=0` и сентинель −200, когда ни output, ни duplex не играют). В микшере на мастер-стрипе появилась строка «M −0.2 · S −0.1 LUFS» (монo, mint; при тишине — «LUFS · тишина», без живого рендера — скрыта). CTest `audio_engine` сверяет счётчик с офлайн-эталоном (фулл-скей 1 kГц ≈ 0 LUFS в обоих окнах за ≤0.8 LU), сентинель цифровой тишины и сброс через `resetMeters`.
