# Loop playback и DAW-оболочка — 1.7.0

15 сентября 2026. Выбранный полуоткрытый диапазон `[start, end)` теперь можно включить как цикл transport. Loop не меняет ревизию и не сохраняется в `.mydawdraft`: это рабочее состояние текущего окна, как playhead.

## Аудиоконтракт

`Renderer` проверяет границы при подготовке плана. В callback он выводит кадр `end - 1`, переносит курсор на `start` перед следующим кадром и продолжает заполнять тот же hardware buffer. Поэтому граница может находиться внутри callback, а короткий цикл может обернуться несколько раз за один вызов без выделений памяти, блокировок, пропущенных или повторённых кадров.

C bridge добавляет `daw_set_loop` и поля `loop_enabled`, `loop_start`, `loop_end` в transport snapshot. Изменение цикла останавливает текущий output plan; следующий Play запускает проверенный план с новыми границами. Если монтаж сократил проект так, что конец цикла оказался вне duration, цикл автоматически отключается.

## Рабочий экран

Окно стало плотнее и ближе к обычной DAW: короткий project header, transport и project actions сверху, timeline tools одной полосой, основная высота отдана дорожкам. Channel header содержит номер, arm, mute, solo, название, take selector и comp. Volume, pan и операции клипа находятся в отдельном strip над увеличенной волной. Активный loop окрашивает диапазон на всех дорожках в оранжевый; обычное выделение остаётся синим.

Это первый проход структуры интерфейса. Он не является финальным visual system: отдельные inspector/mixer panels, масштабирование таймлайна, горизонтальная прокрутка, контекстные меню и адаптация к узким окнам ещё впереди.

## Проверка и открытая граница

Автотест создаёт десятикадровый источник и проверяет последовательность `5, 6, 3, 4, 5, 6` для цикла `[3, 7)`, положение после wrap, непрерывность gain smoothing и отклонение обратного или выходящего за duration диапазона. C smoke проверяет включение, сохранение валидного состояния после ошибочной команды и очистку без project revision.

Этот документ фиксирует loop playback. Следующий срез [1.8.0](33-full-duplex-loop-recording.md) добавил общий AUHAL clock и разбиение проходов на take sources. Для B-010 остаются recovery metadata v2, latency compensation и физическая проверка нескольких циклов.
