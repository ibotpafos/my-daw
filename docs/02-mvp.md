# Спецификация первой версии

## Уровни готовности

**S0 — техническое доказательство:** импорт файла, воспроизведение, запись одного входа, сохранение/открытие, стереоэкспорт. Внешние плагины и ИИ не нужны.

**S1 — рабочая альфа:** законченная запись вокала с дублями, ручным comp, базовым микшером, AU-эффектами и восстановлением. Только после физической проверки можно использовать для пробных реальных сессий с резервной копией.

**S2 — отличие продукта:** workflow-модуль подготовки дублей, варианты обработки, помощник через те же команды. S2 не заменяет исправление дефектов записи из S1.

## Фиксированные границы альфы

Текущий прототип фиксирует проект в 48 kHz: stereo master, float32 внутренние буферы и signed int64 frames на таймлайне. Частота проекта после создания не меняется. Устройство приводится к ней, если поддерживает; иначе предлагается другое устройство/проект, без скрытого асинхронного ресемплинга. Mono/stereo PCM WAV 44,1 / 48 / 88,2 / 96 / 192 kHz конвертируются вне realtime при импорте; формат и аудиоплан проекта остаются 48 kHz.

В S1 — постоянный tempo и размер, аудиодорожки, один master, шины и sends без feedback. MIDI, tempo ramps, surround, video, AAF/OMF, ARA-host, CLAP, VST2, Intel bridge и совместное сетевое редактирование отложены. Это не препятствует WAV/stem обмену с другими DAW.

Мониторинг по умолчанию выключен. При включении software monitoring явно показывается состояние; пользовательский direct monitoring аудиоинтерфейса не переключается тайно. Не включать вход MacBook в его динамики автоматически.

## Ошибки как часть интерфейса

| Ситуация | Поведение |
|---|---|
| Устройство отключено | Завершить доступные записанные кадры, перейти в deviceLost, не заявлять продолжение записи |
| Диск заполнен / writer не успевает | Остановить запись с точной причиной и диапазоном риска; сохранить завершённую часть |
| Медиа отсутствует | Placeholder с длиной и именем, relink; не превращать это в пустой успешный импорт |
| Плагин отсутствует | Сохранить opaque state и маршрутизацию; показать bypass placeholder |
| Плагин упал | Изолированный worker отключить; recovery по спецификации hosting |
| Команда опоздала | Ответ stale_revision с новым revision; никаких частичных изменений |
| ИИ недоступен | Все операции вручную работают; отменяемая фоновая задача завершается ошибкой |
| Более новый проект | Отказ от записи поверх него; read-only только при поддержанной совместимости |

## Пример сквозной приёмки S1

Создать проект 48 kHz, импортировать инструментал, записать три прохода вокала, собрать четыре фразы, сделать fades, добавить EQ и AU-компрессор, создать send на реверберацию, записать volume automation, сохранить, закрыть, открыть и экспортировать WAV. Проверить положение клипов, состояние плагинов, сравнить воспроизведение и экспорт на слух. Затем повторить Save As и открыть копию без доступа к исходному пути.

Успех этого сценария требует приложения и аудио на физическом устройстве. Проверка JSON/SQL и зелёный CI не равны такой приёмке.
